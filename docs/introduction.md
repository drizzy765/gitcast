# Introduction

> git diff → published post.

Gitcast is a privacy-first desktop utility for developers who build in public. One hotkey press captures your active window, reads your git diff, and uses AI to generate platform-ready social media posts in under 60 seconds.

## The Problem

Developers ship constantly. Most of it goes undocumented. Not because they don't want to share — but because context-switching to write content breaks the flow that produced the work in the first place.

## The Solution

Gitcast stays completely out of your way until you need it. No always-on recording. No screen watching. You trigger it when you have a win or a struggle worth sharing.

## What Gitcast generates

- **X (Twitter) posts** — published directly via API
- **LinkedIn drafts** — copy + download framed screenshot
- **PR descriptions** — paste into GitHub
- **Quick wins** — short punchy updates

## Privacy model

- OCR runs locally via Tesseract — text never leaves your machine until you approve
- Screenshots encrypted at rest
- Sensitive content (API keys, tokens) auto-detected and blocked
- Declined screenshots deleted immediately from disk
- No always-on recording — you trigger every capture

## Who it's for

- Indie hackers building in public on X/Twitter
- Developers growing a personal brand
- Founders documenting their build journey
- Anyone who ships but struggles with the content side
