# Changelog

### Added
- Global hotkey capture (`Ctrl+Shift+P` / `Ctrl+Alt+S`)
- Multi-provider AI routing (Groq, DeepSeek, Gemini, Kimi)
- 4 post formats: X Post, LinkedIn, PR Description, Quick Win
- Brutalist web dashboard at localhost:8000
- X (Twitter) publish via API v2
- LinkedIn draft + framed screenshot download
- Sprint Mode — silent capture, batch thread generation
- Article generator with codebase reader
- Post verification checkmark system
- 7-day performance metrics tracking
- Insights dashboard with viral coefficient
- Tone Memory — learns your voice from rated posts
- Viral patterns — proven tweet structures
- Sensitive content detection — blocks API keys, secrets
- Screenshot encryption at rest
- Local JSON storage with Supabase optional sync
- BYOK — bring your own API keys
- Live generation logs in dashboard
- Rate limiting on all API endpoints
- Input validation and prompt injection protection
- Anonymous Posthog analytics
- Sentry error tracking

### Providers supported
Groq, DeepSeek, Gemini, Kimi, Cerebras, OpenRouter

### Platforms
